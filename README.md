# USJ-R School of Computer Studies - BSIT Specialization Tracks

A modern, interactive web showcase for the **University of San Jose-Recoletos (USJ-R) School of Computer Studies** BSIT specialization tracks in **Mobile Applications Development** and **Cybersecurity**.

## 🎯 Overview

This repository serves as a comprehensive resource hub for two exciting career tracks offered in the BSIT program:

| Track | Focus | Duration |
|-------|-------|----------|
| **Mobile Applications Development** | Cross-platform mobile development with Flutter | 3 Semesters |
| **Cybersecurity** | Offensive & defensive security, forensics, and architecture | 3 Semesters |

Both tracks are designed for 2nd-year BSIT students and culminate in industry-ready skills through hands-on, project-based learning.

---

## 📱 Mobile Applications Development Track

A comprehensive Flutter development program that transforms students from beginners to professional mobile developers.

### Key Learning Areas
- **Semester 1:** UI/UX fundamentals, Dart programming, state management (Provider & Riverpod), testing
- **Semester 2:** REST APIs, authentication, Supabase backend, Mapbox location services
- **Semester 3:** Machine learning/AI integration, clean architecture, CI/CD, app store deployment

### Technologies
`Flutter` `Dart` `Riverpod` `Supabase` `Mapbox` `TensorFlow Lite` `Firebase` `GitHub Actions`

---

## 🛡️ Cybersecurity Specialization Track

An intensive CTF-based program that develops students into workforce-ready cybersecurity professionals.

### Key Learning Areas
- **Semester 1:** Offensive security, penetration testing, OWASP Top 10, network exploitation
- **Semester 2:** Digital forensics, incident response, SIEM operations (Splunk/Wazuh)
- **Semester 3:** Threat modeling, secure architecture, security automation, DevSecOps

### Certification Alignment
`CompTIA Security+` `EC-Council CEH` `DFIR`

### Tools & Platforms
`Kali Linux` `Burp Suite` `Metasploit` `Wireshark` `Ghidra` `Splunk` `TryHackMe` `CyberDefenders`

## 🚀 Getting Started

### View the Landing Page

Open `index.html` directly in a modern browser, or serve it locally:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

### Features
- **Modern UI** with animated backgrounds and glass-morphism design
- **Dark/Light theme toggle** for accessibility
- **Responsive design** for desktop, tablet, and mobile
- **Interactive track cards** with skill tags and call-to-actions
