Overview of the three-semester progression.

Semester 1: Offensive Security

"Think Like an Attacker" — 18 weeks of ethical hacking

Weeks 1-2: Foundations

  • Lab environment setup (Kali, VMs)
  • Linux command-line mastery
  • Security documentation practices

Weeks 3-4: Reconnaissance

  • OSINT & passive recon
  • Nmap scanning & enumeration
  • Attack surface mapping

Weeks 5-6: Network Attacks

  • MITM, ARP poisoning, DNS spoofing
  • Service exploitation (SMB, FTP, SSH)
  • Wireshark traffic analysis

Weeks 7-9: Web App Security

  • OWASP Top 10 vulnerabilities
  • SQL injection, XSS, CSRF
  • Burp Suite mastery
Time: 2 minutes
Detail the first half of Semester 1 curriculum.

Semester 1: Offensive Security (cont.)

Weeks 10-12: System Exploitation

  • Metasploit Framework mastery
  • Windows & Linux privilege escalation
  • Active Directory attacks
  • Post-exploitation & persistence

Weeks 13-14: Cryptography

  • Hash cracking with Hashcat/John
  • Password attacks & credential stuffing
  • Cryptographic weaknesses

Weeks 15-16: Reporting

  • Vulnerability assessment methodology
  • Professional pentest reports
  • CVSS scoring & risk ratings

Weeks 17-18: CTF Finals

  • Internal CTF competition
  • Comprehensive pentest report
  • Oral defense of findings
Time: 2 minutes
Complete Semester 1 overview with culminating CTF competition.

Semester 2: Defensive Security

"Defend Like a Guardian" — Detect, analyze, and respond

Weeks 1-2: SOC Fundamentals

  • Security Operations Center roles
  • Defense-in-depth strategy
  • Log management & baselines

Weeks 3-5: SIEM & Detection

  • Splunk & Wazuh deployment
  • Detection rule engineering
  • MITRE ATT&CK mapping

Weeks 6-8: Network Forensics

  • Deep packet inspection
  • C2 traffic identification
  • Zeek IDS & NetworkMiner

Weeks 9-11: Digital Forensics

  • Disk & memory forensics
  • Volatility & Autopsy
  • Windows/Linux artifact analysis
Time: 2 minutes
Transition to defensive security curriculum.

Semester 2: Defensive Security (cont.)

Weeks 12-14: Malware Analysis

  • Static & dynamic analysis
  • Ghidra reverse engineering intro
  • IoC extraction & sandboxing

Weeks 15-16: Incident Response

  • NIST SP 800-61 framework
  • Containment, eradication, recovery
  • Tabletop exercises

Weeks 17-18: Blue Team CTF

  • Defensive CTF competition
  • Group IR simulation
  • Forensics report & defense

Skills Acquired

  • Threat hunting & detection

  • Team-based incident response

Semester 3: Architecture & Research

"Build and Innovate" — Design, automate, and research

Weeks 1-3: Threat Modeling

  • STRIDE & PASTA methodologies
  • Risk assessment frameworks
  • Threat intelligence & APT profiling

Weeks 4-6: Secure Architecture

  • Zero Trust principles
  • Network segmentation & DMZ
  • Cloud & container security

Weeks 7-9: Security Automation

  • Python for security scripting
  • DevSecOps & CI/CD security
  • SOAR & playbook automation

Weeks 10-12: Advanced Research

  • Vulnerability research & fuzzing
  • Buffer overflow introduction
  • CVE analysis & detection rules

Ethics & Academic Integrity

With great power comes great responsibility

Required Conduct

  • Test only in authorized environments
  • No unauthorized system access
  • Responsible vulnerability disclosure
  • Proper attribution for code/tools
  • No sharing CTF solutions during events

Violation Consequences

  • Immediate assessment failure
  • Potential program removal
  • Academic integrity board report
  • Possible legal consequences
  • Industry reputation damage

Ethical hackers protect — they don't exploit for personal gain
